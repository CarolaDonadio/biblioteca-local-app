# Cómo abrir el proyecto

## Vista rápida HTML
Abrí `public/index.html` con doble clic o con Live Server en VS Code.

## Aplicación completa
Las vistas `.php` requieren CodeIgniter 4 y PHP; no funcionan haciendo doble clic. Hay que instalar el framework completo, configurar `.env`, importar `database/schema.sql` y ejecutar `php spark serve`.
